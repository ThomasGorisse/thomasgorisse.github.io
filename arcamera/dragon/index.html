01 · Spatial Pipeline

Why grounding in real AR first changes everything

Three deterministic steps from static mesh to a living scene physically locked to your room.

01

Anchor in Real AR

Load any local .glb, .stl, or .obj model (or turn a photo into 3D), detect floor or desk planes with ARCore or ARKit, and pin an anchor into physical space.

02

Lock Real Lighting & Scale

Google Filament renders PBR reflections matched to room lighting and casts real-time ground shadows at exact 1:1 scale with true camera perspective.

03

Bring the Scene to Life

Feed that spatially verified AR capture straight into video animation — so motion feels physically rooted to the wood planks and light of your living room.

DragonARScreen.kt · Jetpack Compose ARSceneView 
var anchor by remember { mutableStateOf<Anchor?>(null) }

ARSceneView(
    modifier = Modifier.fillMaxSize(),
    planeRenderer = true,
    onSessionUpdated = { _, frame ->
        if (anchor == null) {
            anchor = frame.getUpdatedPlanes()
                .firstOrNull {
                    it.type == Plane.Type.HORIZONTAL_UPWARD_FACING
                }
                ?.let { it.createAnchorOrNull(it.centerPose) }
        }
    }
) {
    val dragon = rememberModelInstance(modelLoader, "models/dragon.glb")
    anchor?.let { a ->
        AnchorNode(anchor = a) {
            dragon?.let {
                ModelNode(modelInstance = it, scaleToUnits = 1f)
            }
        }
    }
}
