Open source

SceneView: 3D & AR in a few lines of UI code

I created SceneView after Google stopped Sceneform. On Android it is Compose-first, on top of Filament and ARCore. On Apple platforms it is SwiftUI on RealityKit. It reaches the web, Flutter and React Native too.

// The chair above, in a Compose screen
val engine = rememberEngine()
val modelLoader = rememberModelLoader(engine)

SceneView(engine = engine, modelLoader = modelLoader) {
    rememberModelInstance(modelLoader, "chair.glb")?.let {
        ModelNode(modelInstance = it, scaleToUnits = 1f)
    }
}

It is written for AI assistants as much as for people: the repo ships an MCP server, AGENTS.md and llms.txt. In 2026 it was accepted into Anthropic’s Claude for Open Source Program.
