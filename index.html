ARScreen.kt · Jetpack Compose 
var anchor by remember { mutableStateOf<Anchor?>(null) }

ARSceneView(
    modifier = Modifier.fillMaxSize(),
    planeRenderer = true,
    onSessionUpdated = { _, frame ->
        if (anchor == null) {
            anchor = frame.getUpdatedPlanes()
                .firstOrNull {
                    it.type == Plane.Type.HORIZONTAL_UPWARD_FACING
                }
                ?.let { it.createAnchorOrNull(it.centerPose) }
        }
    }
) {
    val dragon = rememberModelInstance(modelLoader, "models/dragon.glb")
    anchor?.let { a ->
        AnchorNode(anchor = a) {
            dragon?.let {
                ModelNode(modelInstance = it, scaleToUnits = 1f)
            }
        }
    }
}

Multi-agent engineering, in production

Senior Mobile SDK EngineerAI Agent Pipeline

I build and own cross-platform mobile SDKs, and designed the autonomous pipeline behind them—how architecture, code, visual verification, and releases move from specification to device.

Specialized agents implement, inspect, and test. I own the architecture, API contracts, and quality gates.

  • 01Multi-model orchestration

    Routing architecture, code, media, and QA to the right model and effort instead of locking into one tool.

  • 02Independent verification

    The agent that writes a change never approves it. Visual audits, browser verification, and separate review passes catch regressions early.

  • 03Hard quality gates

    Binary-compatibility checks on public APIs, screenshot diffs, automated on-device QA, and CI on every PR.

  • 04Assistant-ready SDKs
